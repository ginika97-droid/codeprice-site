# CodePrice website draft

This is a static, responsive site with no build step:

- `index.html` — product landing page
- `privacy.html` — privacy notice
- `sample-shop-product.html` — fictional, original product page for CodePrice testing and preview screenshots
- `assets/codeprice-store-icon-128.png` — CodePrice brand icon

To publish, upload the contents of this folder to the website repository (or configure the repository’s Pages source to this folder). Then add `codeprice.co.uk` as the custom domain in the hosting settings and set the DNS records required by that host. Confirm HTTPS is active and both the home page and `privacy.html` load before using the URL in the Chrome Web Store.

The current draft does not link to the Chrome listing because the listing is not public yet. Add its public URL to the home page after launch.

The sample product page uses invented shop/product/offer details and a CSS illustration. It contains no retailer logos, product photography, or third-party assets. Use it as the page behind the CodePrice popup when capturing a demonstration screenshot; keep the fictional/demo notice visible where practical.
